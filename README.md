## 📋 Visão Geral

**Ink Soul** é uma landing page premium desenvolvida para estúdios de tatuagem, focada em conversão de visitantes em clientes agendados.

Projeto criado como **case de estudo**, demonstrando qualidade visual, UX e organização técnica.

> ⚠️ Este não é um template genérico.  
> Cada projeto é 100% personalizado conforme a identidade do cliente.

## ✨ Funcionalidades

### 🎨 Design & UX
- Dark mode com gradientes
- Totalmente responsivo
- Animações suaves
- Glassmorphism

### 📱 Seções
- Hero com contadores animados
- Artistas e especialidades
- Galeria com filtros e modal
- Serviços
- Depoimentos
- Agendamento integrado ao backend
- FAQ interativo
- Footer completo

## ⚡ Recursos Técnicos
- Scroll animations
- Barra de progresso
- Contadores automáticos
- Filtros dinâmicos
- Modal de sucesso
- Background com partículas
- Botão Back to Top

## 🚀 Tecnologias

### Frontend
- HTML5
- Tailwind CSS (CDN)
- JavaScript Vanilla
- Font Awesome

### Backend
- Flask
- SMTP (Gmail)
- CORS
- python-dotenv
